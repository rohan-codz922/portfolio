CampusPrint

Print-shop management for a college campus — web app, REST API and an admin desk, built end to end

Live demo — college project

A campus printing service where students upload a document, see the exact price, and follow their print from their phone — while the print desk runs the whole queue from one admin screen. I built it end to end: a Kotlin + Spring Boot REST API with JWT and role-based access (student / admin), a React web app, and a Flutter mobile client in progress. The server does everything a student shouldn't be trusted with — it counts the pages itself and calculates the price, so totals can't be tampered with. Every new account is locked until an emailed one-time code is confirmed, and large prints (20+ sheets) must be paid up front by UPI, with the payment screenshot checked by the desk before printing can start — enforced on the server, not just in the UI. The API is protected with rate limiting, login lockout, hashed codes and strict security headers.
